# Code Implement Skill

**功能**：实现功能代码并编写全面的测试

**输入**：
- 功能需求
- 现有代码库结构
- 技术栈（语言、框架）

**输出**：
1. 功能实现代码
2. 单元测试代码
3. 集成测试（如需要）
4. 测试覆盖率报告
5. 代码文档

**实现流程**：
1. 分析需求，设计接口
2. 遵循现有代码风格实现功能
3. 编写单元测试（覆盖正常路径和边界情况）
4. 运行测试，确保通过
5. 优化代码质量
6. 生成覆盖率报告

**代码质量标准**：
- ✓ 遵循项目代码规范
- ✓ 代码清晰易读
- ✓ 适当注释
- ✓ 错误处理完善
- ✓ 性能合理

**测试要求**：
- ✓ 测试覆盖率 ≥ 85%
- ✓ 测试正常路径
- ✓ 测试边界条件
- ✓ 测试异常情况
- ✓ 测试可重复执行

**测试框架推荐**：
- JavaScript/TypeScript: Jest, Vitest
- Python: pytest
- Java: JUnit
- Go: testing

**输出格式**：
```
✓ 功能实现完成
修改文件：
- src/feature.ts (新增 150 行)
- tests/feature.test.ts (新增 80 行)

测试结果：
- 测试通过：15/15
- 覆盖率：92%

代码质量：
- Lint 检查：通过
- 类型检查：通过
```

**使用场景**：
- 新功能开发
- Bug 修复
- 重构优化
- 技术债务清理
