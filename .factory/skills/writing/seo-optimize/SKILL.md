# SEO Optimize Skill

**功能**：优化内容的搜索引擎优化表现

**输入**：
- 文章内容
- 目标关键词列表
- 目标平台（Google、百度等）

**输出**：
- SEO 优化后的内容
- 关键词密度分析
- 元数据建议（标题、描述、标签）
- SEO 检查报告

**优化项目**：
1. 标题优化（包含主关键词，长度合适）
2. 元描述优化（150-160字符，包含关键词）
3. 标题结构（H1-H3合理使用）
4. 关键词布局（自然融入，避免堆砌）
5. 内容质量（原创性、可读性、价值）
6. 内部链接建议
7. 图片 alt 标签
8. URL 结构建议

**检查清单**：
- ✓ 标题包含主关键词
- ✓ 关键词密度 1-2%
- ✓ 有 H1 标题
- ✓ 有 H2/H3 子标题
- ✓ 段落长度适中（100-150词）
- ✓ 包含内部/外部链接
- ✓ 图像有 alt 文本
- ✓ 内容原创性强

**使用场景**：
- 博客文章发布前
- 产品页面优化
- 着陆页优化
