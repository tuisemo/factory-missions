# Competitor Analysis Skill

**功能**：深入对比竞品或技术方案，提供决策依据

**输入**：
- 目标产品/方案
- 竞品/对比方案列表（3-5个）
- 关注维度（功能、性能、价格、用户体验等）

**输出**：
1. 详细对比表格
2. 每个方案的优劣势分析
3. 综合评分
4. 推荐方案及理由
5. Sources（数据来源 + 访问时间，2025-2026）

**对比维度（可扩展）**：
- 功能特性
- 性能表现
- 用户体验
- 定价策略
- 市场占有率
- 用户评价
- 技术架构
- 生态支持
- 成熟度
- 扩展性

**工作流程**：
1. 使用 WebSearch 搜索每个方案的最新信息（2025-2026）
2. 收集官方文档、评测报告、用户反馈
3. 按维度整理数据
4. 生成对比表格
5. 分析优劣势
6. 给出推荐

**输出格式**：
```markdown
# 竞品对比分析报告

## 方案概览
[简要介绍各方案]

## 详细对比表
| 维度 | 方案A | 方案B | 方案C |
|------|-------|-------|-------|
| 功能 | ... | ... | ... |
| 性能 | ... | ... | ... |
| ... | ... | ... | ... |

## 优劣势分析
### 方案A
- 优势：...
- 劣势：...

## 推荐
**推荐方案**：方案X
**理由**：...

## 数据来源
- 来源1 + 访问时间
- ...
```

**使用场景**：
- 技术选型
- 产品定位
- 市场调研
- 投资决策
