# Literature Summary Skill

**功能**：深度总结文献、研究报告、技术文档，提取核心观点

**输入**：
- 研究主题
- 文献/资料来源列表（URL或文档）
- 时间范围（优先 2025-2026）

**输出**：
1. 核心观点总结
2. 关键数据提取
3. 趋势分析
4. 研究空白
5. 未来方向建议
6. Sources（来源 + 访问时间）

**总结结构**：
```markdown
# [主题] 文献总结报告

## 核心观点
[提取 3-5 个最重要的观点]

## 关键数据
[表格形式展示重要数据]

## 趋势分析
[分析当前趋势和未来方向]

## 研究空白
[指出尚未解决的问题]

## 未来方向建议
[基于趋势的建议]

## 参考文献
1. [标题](URL) - 访问时间
2. ...
```

**工作流程**：
1. 使用 FetchUrl 或 WebSearch 获取文献
2. 快速浏览，提取核心内容
3. 识别关键数据和观点
4. 分析趋势和模式
5. 总结并格式化输出

**质量标准**：
- 信息准确，来源可靠
- 观点客观，避免偏见
- 数据完整，标注清晰
- 结构清晰，易于理解

**使用场景**：
- 学术研究
- 技术调研
- 行业分析
- 投资研究
